# Alfabetet och uttal

**Sammanfattning:** serbiska skrivs med både latin och kyrilliska. Varje bokstav har ett ljud, så ord uttalas som de skrivs.

## Två alfabet
- Båda används i vardagen. Appen visar latin och kyrilliska under.
- Tre latinska bokstavspar motsvarar en kyrillisk bokstav: **lj = љ**, **nj = њ**, **dž = џ**.

## Ljud som skiljer sig från svenskan
| Bokstav | Uttal | Exempel |
|---|---|---|
| c | ts | **c**rkva (kyrka) |
| č | hårt "tj", som engelska *ch* i *church* | **č**aj |
| ć | mjukare "tj" | sre**ć**a |
| dž | hårt "dj", som engelska *j* i *jam* | **dž**em |
| đ | mjukare "dj" | **đ**ak |
| š | sj-ljud, som engelska *sh* | **š**ta |
| ž | tonande sj, som franska *j* i *jour* | **ž**ivjeli |
| j | som svenskt j | **j**ako |
| h | hårdare än svenskt h | **h**vala |
| r | rullande. Kan vara vokal: *prst* (finger) | **r**akija |

Č/ć och dž/đ är svåra även för många infödda. Du blir förstådd även om du blandar ihop dem.
