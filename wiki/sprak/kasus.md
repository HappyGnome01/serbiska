# Kasus

**Sammanfattning:** serbiska substantiv ändrar ändelse beroende på sin roll i meningen. Det finns **7 kasus**. Som nybörjare räcker det att känna igen mönstret. Lär dig fraserna som helheter.

## Kasus som dykt upp i lektionerna
| Kasus | Roll | Exempel |
|---|---|---|
| Nominativ | grundform, den som gör något | **Kafa** je dobra. |
| Ackusativ | det man vill ha, ser, dricker | Hoćeš li **kafu**? |
| Genitiv | "av", mängder | Čašu **vode**. |
| Lokativ | var något är (efter *u, na*) | u **Švedskoj**, u **bašti** |
| Instrumental | "med" (efter *sa*) | sa **mlijekom** |

Övriga kasus (dativ, vokativ) läggs till här när de dyker upp.

## Tumregler för ord på -a (kvinnliga)
- Ackusativ: **-a → -u** (kafa → kafu, rakija → rakiju)
- Genitiv: **-a → -e** (voda → vode)
- Lokativ: **-a → -i** (bašta → bašti, Švedska → Švedskoj för ord som slutar på -ska)
